Housekeeping

Every night at 2:30 the cloud throws away raw sync history older than the window below. It never touches what the phones read — bills, customers, stock and day accounts are in projections, and no figure in the app changes.

Deleting frees room inside the database; it does not shrink the file on disk. The volume bar only falls after a VACUUM FULL, which needs as much free space as the table is big — so resize first, prune second, reclaim last.
